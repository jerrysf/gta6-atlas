## The official layout isn't out yet

Rockstar hasn't published GTA 6's button mapping. What's below is the **expected layout** based on GTA V's modern scheme — the franchise's control grammar has been stable for a decade, and the Extended Look confirms the same third-person shooting/driving foundation. We'll document the actual mapping on launch day.

## Expected on-foot controls (PS5 / Xbox)

| Action | PS5 | Xbox |
|---|---|---|
| Move / Sprint | Left stick / X | Left stick / A |
| Aim | L2 | LT |
| Fire | R2 | RT |
| Reload | Square | X |
| Jump / Vault | X? — see note | A? — see note |
| Cover | R1 | RB |
| Melee | Circle / Square | B / X |
| Interact | Triangle | Y |
| Character swap | Hold D-pad down (expected) | Hold D-pad down (expected) |

*Jump and sprint share the X/A region in GTA V — exact GTA 6 mapping may differ.*

## Expected driving controls

| Action | PS5 | Xbox |
|---|---|---|
| Accelerate / Brake | R2 / L2 | RT / LT |
| Handbrake | R1 | RB |

## Confirmed: dual-protagonist swapping

The Extended Look shows **switching between Jason and Lucia mid-gameplay** — the first GTA built around two protagonists. Whether free-roam swap works like GTA V's character wheel or has story constraints is unconfirmed.
